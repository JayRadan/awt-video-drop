## Pipeline
1. **Workspace**: `mkdir -p /home/claude/gold`; copy this skill's `scripts/*.py` and `assets/*` there. `mcp__claude-code-remote__add_repo` JayRadan/awt-video-drop (push) and `git clone --depth 1` to `/home/claude/awt-video-drop`; copy `assets/ai_bumper.mp4` into `/home/claude/gold/assets/` if present there.
2. **Data**: `python3 -I fetch_coinbase.py 400 candles.json`. Note last close, 24 h high/low, 2-week range. Set `LEVEL=<spot key level>` and, if the analysis has a second level (target/wall), `LEVEL2=<spot>`; set `LEVEL_LABEL` / `LEVEL2_LABEL` to the role ("4,150 FUT ≈ 4,132 SPOT · PUT WALL").
3. **Script** → `script.txt`, exactly **10 paragraphs** (paragraph = scene): (0) hook: contrarian claim + stake, no brand name (1) context / the trade (2) overview of the signals (3)–(7) one signal or argument each (8) the view / the plan (9) outro: the comment question + "I'll keep updating this as it develops. This is my own analysis and not financial advice. Trade your own plan, manage your risk, and I'll see you in the next one." 650–1,000 words, < 5,000 chars.
4. **Voice**: `vidiq_voiceover_generate` with voiceId `awEuEpUHQ0v6BHQ2QNgl` (Wolf Trader) → poll → `curl -o voice.mp3 "<audioUrl>"`.
5. **Timing (word-accurate)**: `python3 align.py script.txt voice.mp3 1.0 timing.json` — offline speech recognition aligns every word; this is what keeps captions and scene changes in sync. Do not use the old proportional `timing.py`.
6. **Scene plan** → `plan_<date>.py` exposing `PLAN = [...]`, one entry per paragraph, choosing a **different template for consecutive scenes** from: `bumper` (hook over the AI clip; falls back to hero chart), `hero_chart` (full-bleed tilted chart, camera push; `title`, `headline "L1|L2"`, `zoom`, `level2`, `entries [(price,col,label,at)]`, `rejections`, `break_at`), `split` (tilted chart + sliding rows: `rows [{k,v,sub,col,at,h}]`, `footer`), `impact` (count-up/number card: `kicker`, `value`/`count (a,b)`, `sub "L1|L2"`), `quote` (kinetic typography of every sentence as spoken; `hot [WORDS]`), `timeline` (month/period bars: `labels`, `vals`, `highlight`, `negative`, `callouts [{text,x,y,col,at,f}]`, `note`), `chain` (cause→effect boxes with arrows + optional `sparks` sparklines), `cards` (numbered list + chart thumb), `outro`. Map the user's content: entries/levels → hero_chart; lists → cards/split; comparisons or mechanisms → chain; seasonality/calendar → timeline; the punchiest paragraph → quote; a single big number → impact. Bullish view: use GREEN for verdict colours and set `break_at` to none (or rely on `entries`). Keep all numbers exactly as the user gave them.
7. **Preview**: render 6–8 frames with `render(t)` from `engine2.py` (exec the module without `__main__`) and `Read` the contact sheet. Check: no text overflow, chart levels visible, hook readable, captions not colliding.
8. **Render** (two halves in parallel, ≈ 0.8 s/frame each → ~60 min for 5 min of video): `SCENES=plan_<date> LEVEL=.. LEVEL2=.. LEVEL_LABEL=.. LEVEL2_LABEL=.. VDATE="GOLD UPDATE · DD MON YYYY" CTA=.. python3 engine2.py timing.json A.mp4 0 <mid>` and `B.mp4 <mid> <end>` (end = last scene end + 2.0); wait with a background `until grep -q "^done" A.log && grep -q "^done" B.log` loop; concat with ffmpeg.
9. **Audio**: `SCENES=plan_<date> python3 sfx2.py timing.json voice.mp3 music.mp3 audio.wav` (voice delayed 1 s, music ducked, template-driven effects: transition whoosh/riser/thud, data ticks on chart builds, impact on number cards, word ticks in quotes, ascending blips on lists, chord on outro). Mux: `ffmpeg -i video.mp4 -i audio.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest AWT_Gold_Update_<date>.mp4`. Spot-check two frames across the join. `SendUserFile` the MP4.
10. **Title / description**: title ≤ 100 chars; description = summary of the signals, chapters from `timing.json` scene starts (m:ss), data note ("Chart: PAXG-USD hourly via Coinbase as a spot-gold proxy; illustrative panels are marked"), disclaimer, AI note, hashtags.
11. **Thumbnail**: `vidiq_user_videos` (limit 2) → last two thumbnails as `referenceImages` → `vidiq_generate_thumbnail` with a composition that differs from the last one (presenter left/right/centre, chart framing, accent colour per the growth rules), big 2–3-word consequence headline. `vidiq_score_thumbnail` once; if < 45, one `vidiq_refine_thumbnail` with the scorer's tip, then stop.
12. **Publish long**: copy MP4 to `videos/`, commit, push, verify the raw URL returns 200, `createScheduledPost` (blogId 7357453, now+10 min Berlin, youtube, `type video`, privacy public, EDUCATION, madeForKids false, isAiGeneratedContent true, tags, `firstCommentText` = the comment question). After the result shows a `static.metricool.com` media URL, `git rm` + push.
13. **Short (free)**: `SHORT_DATE SHORT_TITLE SHORT_PARA=<key paragraph> python3 short.py timing.json <long>.mp4 AWT_Short_<date>.mp4 56` (hook + key paragraph + conclusion, large captions, footer). Publish the same way with `type short`, title ending `#shorts`, description + `firstCommentText` linking the long video (use the long video's youtu.be id once known — update the Short post with `updateScheduledPost` if it is still pending). Schedule 30–60 min after the long video; on weekends a second Short next morning from another paragraph.
14. **After publish**: `send_later` 15–20 min → `vidiq_user_videos` → `vidiq_update_video_thumbnail` (channelId, videoId, thumbnail=imageUrl); update the Short's links; report both `https://youtu.be/<id>` links and credits used.
