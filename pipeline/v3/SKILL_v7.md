## Hard rules
- **His analysis is the content.** Clean sentences, add a hook / transitions / recap only. Never add, remove or change a claim, level, target, entry, probability or view. Never invent prices, targets or invalidation. Preserve his uncertainty and qualifications.
- **Evidence, not decoration.** Every important price, %, date, target and comparison appears on screen when it is spoken. Charts use real data (`fetch_coinbase.py`, PAXG-USD ≈ spot) and always show instrument, timeframe, dates (UTC), units; spot vs futures named (e.g. "4,000 strike on December gold futures — not spot"). Never use AI-generated charts as evidence. Thumbnails may not fake a chart either.
- **Observation vs interpretation vs scenario** is always labelled (beat `kind`: observation / data / context / interpretation / scenario / plan). Projections live only in the hatched "SCENARIO · MY VIEW · NOT PRICE ACTION" region and start from the real last close (`["asof","close"]`).
- **Verify before showing.** Facts and headlines are checked (publisher, title, publication date, event date, URL) and recorded in `sources_<id>.json` with data timestamps and asset rights. Never fabricate headlines, quotes, screenshots, trades or performance claims. If a figure in his analysis can't be verified or is contradicted, show it with an on-screen ⚠ UNVERIFIED / CONTRADICTED flag and **stop before publishing**: tell him which claims fail and let him decide (correct the line, drop it, or publish with the flag).
- **QA gate:** do not publish until `qa.py` PASSes (or Jacob explicitly accepts the listed WARN/BLOCK items). Never publish unfinished tests.
- Spoken + on-screen disclaimer "This is my own analysis and not financial advice."; YouTube description notes AI voice/visuals; Instagram `isAiGenerated: true`.

- Visual direction: premium dark documentary, restrained gold/red, clean charts, phone-readable text. No hooded traders, gold-bar piles or unrelated stock footage in videos. Generated imagery only for clearly illustrative scenes.
- Credits: never `vidiq_generate_video`, `vidiq_generate_clips`, `vidiq_motion_graphics`, `vidiq_compose`, `vidiq_generate_broll`. Budget ≈ voice (14 credits / 1,000 chars) + trailer voice (~8) + title scores (5 each, max 3).

## Pipeline (scripts in repo `pipeline/v3/`)
1. **Workspace**: clone repo, `mkdir work && cp pipeline/v3/* work/`, music from `assets/music.mp3`.
2. **Data**: `python3 -I fetch_coinbase.py 500 candles_all.json`; cut to the as-of hour → `candles_<id>.json`. All chart prices/changes are computed from it.
3. **Script** → `script.txt` (his words; paragraphs). **Voice** → `voice.mp3`. **Timing**: `python3 align.py script.txt voice.mp3 1.0 timing.json` (word-accurate; repairs squeezed clusters).
4. **Fact-check** (background subagent while you storyboard): every non-chart number, quote, event and 3–5 real headlines from the analysis day → `sources_<id>.json` (publisher, title, date, URL, verbatim quote, verdict VERIFIED/PARTLY/NOT FOUND/CONTRADICTED, rights).
5. **Storyboard** `sb_<id>.json` (16x9): beats group adjacent sentences one visual explains. Structure: hook → evidence → explanation → competing scenario → triggers/invalidation; alternate dense evidence with simple moments. Each beat: `sents [i0,i1]`, `kind`, `storyboard` (intent), `visual` (template + items, each timed with `at_sent`/`at_word` so it lands on the spoken word), `source_ids`, `source_text` (on-screen source line), `sound` cues. Templates: `chart` (view keyframes = camera, `reveal`, `zone`, `level`, `highlight` exact candle, `measure` computed change, `scenario` path, `note`), `headline` (real headlines, publisher + date), `stat`, `compare`, `list`, `mechanism`, `scenarios` (his probabilities, labelled "not market prices", focus follows narration), `triggers` (+ invalidation bar), `title`, `outro`. Export for review: `python3 sb_export.py sb.json timing.json sources.json qa_frames storyboard.html`.
6. **Preview** before rendering: `python3 preview.py sb.json timing.json prev/x B01 B05 …` and Read the sheet at full size; fix overlaps, overflow, label collisions.
7. **Render** long: two halves in parallel `python3 engine3.py sb.json timing.json A.mp4 0 <mid>` / `B.mp4 <mid> <end>` (~0.07 s/frame/process alone). **Sound**: `python3 sfx3.py sb.json timing.json voice.mp3 music.mp3 audio.wav documentary` (restrained; cues only where the storyboard asks; −14 LUFS, ≤ −1.5 dBTP). Concat + mux (`-c:v copy`).
8. **Trailer Short** (separate edit, 9:16, ≤ 60 s): its own script from his words with ONE insight + escalating tension + clear payoff, keeping the qualification and invalidation (e.g. "If that happens, I'm out at 4,100"). Own voice + `sb_trailer.json` (`"format": "9x16"`, `audio_profile: trailer`): immediate visual hook, chart reveals synced to words, brief `silence` before the twist, `riser_hit`/`hit` only on meaningful reveals. Render with engine3 + `sfx3.py … trailer`.
9. **Thumbnails**: three distinct concepts, each one market tension, minimal text, real data only (`thumbs.py` pattern), checked at 168×94 / 246×138 / 360×202 via `qa.py --thumbs`. Pick one; the video must fulfil its promise. If Jacob wants a cinematic AI background, give him a ChatGPT prompt for an illustrative scene with no chart and no hooded figure, and overlay our text.
10. **QA**: `python3 qa.py sb.json timing.json script.txt sources.json long.mp4 --vertical short.mp4 sb_trailer.json timing_trailer.json script_trailer.txt --thumbs A.jpg B.jpg C.jpg` → `qa_<id>.md`. Checks numbers vs narration/sources/candles, chart labels vs candles, evidence beats have sources, flagged sources are flagged on screen, caption sync, loudness/peaks/clipping, phone-size contact sheets (Read them), thumbnails small. BLOCK → fix or ask Jacob.
11. **Publish** (only after PASS/acceptance): long + trailer via Metricool (drop repo, `git rm` after), Reel via vidIQ (`videoUrl` = the YouTube Short), description lists the source manifest (publisher, date, URL) and chapters from beat starts. `send_later` ~60 min to verify, set thumbnail with `vidiq_update_video_thumbnail`, report links; remind the manual YouTube card step when previous videos are referenced.
